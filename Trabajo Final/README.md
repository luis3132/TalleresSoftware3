# Proyecto Final: AutoLife

En esta entrega se realizó un análisis de rendimiento utilizando JMeter para el proyecto AutoLife, considerando el número de solicitudes y los tiempos de respuesta para despliegues con Docker y MicroK8s, empleando configuraciones de 1, 2 y 3 réplicas.

El repositorio incluye:
* Informes de rendimiento y materiales de presentación.
* Resultados generados por JMeter, organizados en las carpetas **Pruebas** y **Resultados**.

Los repositorios del código fuente del proyecto están disponibles a continuación:
* AutoLife Backend: https://github.com/luis3132/AutoLifeBE
* AutoLife Frontend: https://github.com/luis3132/AutoLifeFE
